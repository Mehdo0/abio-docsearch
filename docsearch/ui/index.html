Mode d'emploi

Trois gestes, et c'est trouvé

Aucun terminal, aucune ligne de commande. Tout se passe dans cette fenêtre.

01

Analyser le partage

Onglet Index, « Ajouter un dossier », choisis le lecteur réseau, puis « Lancer l'analyse ». À refaire quand les fichiers changent : le scan incrémental ne relit que les noms.

02

Chercher

Tape un nom, un dossier ou quelques mots. Les accents et les majuscules n'ont pas d'importance. Filtre par type avec les pastilles.

03

Prévisualiser

Survole un résultat : la première page s'affiche à droite. Double-clic ou Entrée ouvre le document dans Office ou le lecteur PDF.
